## About the Project
This repository contains my submission for Assignment 1 of the Introduction to Web Technologies course. For this semester-long project, I selected **Tary Ethno Cafe** in Astana. It is a real coffee shop that combines modern specialty coffee with traditional Kazakh recipes and ingredients like roasted millet (tary), balkaymak, and kurt.

## Website Pages
The website consists of 4 unstyled semantic HTML5 pages:
- **`index.html`** — Homepage with information about the cafe, our visit and quote from the head barista, cultural events, and opening hours.
- **`menu.html`** — Menu price list with a data table, milk customization lists, the millet roasting process, and a glossary of traditional ingredients.
- **`booking.html`** — Table reservation page with a complete form (guest contact info, visit date, party size, hall choice, occasion, and special requests).
- **`colophon.html`** — Technical page explaining how the site was built, semantic markup decisions, validator status, and technical tags (`code`, `pre`, `kbd`, `samp`).

## Submission Documents
- **`tag-checklist.md`** — Table listing all required tags with their exact file names and line numbers.
- **`task-a-anatomy.md`** — Source code analysis of a real competitor website (Costa Coffee Kazakhstan), identifying 3 structural mistakes.
- **`task-b-written.md`** — Written explanation of what a web page is made of, how the browser renders HTML, and explanations of semantic tag choices.
- **`ai-log.md`** — Log of conceptual questions asked to AI during the assignment, in accordance with the course AI policy.
- **`report.md`** — Combined report of Task A, Task B, and the tag checklist.
- **`images/`** — Photos of the cafe interior, latte, and traditional baursaks.

## Notes
- As required by the assignment rules for Week 1, no CSS or JavaScript was used. All pages rely on clean HTML5 semantic structure and browser default styling.
