## About the Project
This repository contains our team submission for Assignment 1 of the Introduction to Web Technologies course. For our semester-long project, we selected **Tary Ethno Cafe** in Astana. It is a real coffee shop that combines modern specialty espresso culture with traditional Kazakh recipes and ingredients like roasted millet (tary), balkaymak, and kurt.

## Website Pages
The website consists of 4 unstyled semantic HTML5 pages:
- **`index.html`** (by Zamrat Zhasulan) — Homepage with cafe history, in-person quote from head barista Aigerim Kassymova, cultural events, and opening hours.
- **`menu.html`** (by Zamrat Zhasulan) — Menu price list with relational data table, milk customization lists, millet roasting process, and traditional ingredients glossary.
- **`booking.html`** (by Zhaksylyk Adilet) — Table reservation page with accessible form (guest contacts, visit date, party size, hall choice, occasion, and special requests).
- **`colophon.html`** (by Zhaksylyk Adilet) — Technical page documenting markup architecture, validator results, and technical tags (`code`, `pre`, `kbd`, `samp`).
